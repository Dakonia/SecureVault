# 06 · Навыки и ресурсы (что освоить)

Список навыков/технологий, которые нужны для реализации, с приоритетом.

## Критично (без этого не собрать)
- **Криптоконцепции**: симметричное шифрование, обмен ключами (X25519), envelope encryption, Shamir Secret Sharing. Не изобретать — понять, чтобы правильно применять libsodium/age.
- **age / libsodium**: как шифровать данные и делать конверты под получателей.
  - age: https://age-encryption.org , `age-plugin-yubikey`: https://github.com/str4d/age-plugin-yubikey
  - libsodium: https://doc.libsodium.org
- **YubiKey (PIV/FIDO2)**: настройка, привязка расшифровки к ключу, PIN, восстановление.
  - https://developers.yubico.com
- **WireGuard**: конфигурация сервер/клиент, ключи, closed-контур. https://www.wireguard.com/quickstart/
- **LUKS2 + dropbear-initramfs**: шифрование диска сервера и удалённый unlock при ребуте.
  - cryptsetup FAQ: https://gitlab.com/cryptsetup/cryptsetup/-/wikis/FrequentlyAskedQuestions

## Важно
- **Tauri**: сборка десктоп-приложения, работа с файлами/крипто из Rust. https://tauri.app
- **Rust (базово)** — для Tauri-бэкенда и, возможно, серверного API (axum).
- **nftables / fwknop (SPA)**: default-drop, открытие порта по секретному пакету.
  - fwknop: https://www.cipherdyne.org/fwknop/
- **mTLS**: генерация CA, клиентских сертификатов, проверка на сервере.
- **PostgreSQL**: базовое администрирование, хранение blob.

## Полезно (позже)
- **restic** (бэкапы) + age: https://restic.net
- **MinIO** (объектное хранилище): https://min.io
- **Tesseract / PaddleOCR** (локальный OCR расписок/чеков).
- **Metabase** (аналитика, только для согласованных агрегатов): https://www.metabase.com

## Что уже есть в контексте проекта CleanWindows (переиспользовать)
- Опыт с образами дисков/съёмными носителями (ЭЦП ImDisk) — пригодится для понимания работы с ключами-носителями.
- Практика передачи/настройки 30 машин — та же логистика для раскатки клиентского приложения и ключей.

## Порядок изучения
1. age + age-plugin-yubikey (собрать мини-прототип: зашифровать файл под YubiKey, расшифровать).
2. WireGuard (поднять туннель клиент↔сервер).
3. LUKS + dropbear на тестовом сервере.
4. Tauri (обернуть шаги 1–2 в программу).
5. fwknop + nftables + mTLS (закрыть контур).
