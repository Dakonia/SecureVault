# Закрытое хранилище отчётов — проектная документация

Внутренний проект: защищённое хранилище отчётов, цифр и документов ресторанов.
Главная идея — **zero-knowledge**: данные шифруются на устройстве директора, сервер хранит только нечитаемый шифротекст. Открыть можно только своим ключом.

## Состав системы (кратко)
- **30 директоров** — каждый сдаёт своё, видит только своё.
- **3 человека с полным доступом** — видят всё, скачивают, правят, комментируют. Опасные действия — только «2 из 3».
- **1 физический сервер** — под нашим контролем, хранит только зашифрованное.

## Ключевой принцип, о котором нельзя забыть
Сервер **никогда** не должен видеть открытые данные и открытые ключи. Всё, что попадает на сервер, уже зашифровано на клиенте. Любое отклонение от этого ломает всю модель защиты.

## Честные границы (зафиксировано с заказчиком)
- Ключи есть у людей — их могут законно потребовать у владельцев. Техникой не закрывается.
- Фото экрана на телефон — принятый риск, не защищаем.
- Зарплаты и ФИО — персональные данные (ФЗ-152), хранение в РФ, доступ по журналу.
